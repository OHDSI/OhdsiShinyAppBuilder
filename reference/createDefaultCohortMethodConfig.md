# createDefaultCohortMethodConfig

Create an R list with the cohort method config specification
(depreciated)

## Usage

``` r
createDefaultCohortMethodConfig()
```

## Value

An R list with the module config settings

## Details

User specifies the settings to create a default config for a cohort
method module
